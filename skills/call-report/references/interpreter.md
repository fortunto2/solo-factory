# interpreter (a MODE, stacked on any type)

Use when the owner relied on live translation (foreign-language call, official visit, negotiation). Add these sections to the chosen type's report.

- **Key phrases**: the original line and the translation side by side, for terms, amounts, dates, conditions and anything the owner may need to repeat or quote back. Original first, with `t`.
- **Who promised what**: each promise or condition, speaker, original wording, translation. Translation drift matters here: if the live translation and the transcript disagree, show both.
- **Words to learn or confirm**: terms the owner stumbled on, with a plain gloss.
- **Replies suggested but not used**: only if they show a gap the owner should close next time.

Quote the source language exactly; ASR in a non-native language is weaker, so flag doubtful spans rather than smoothing them.
