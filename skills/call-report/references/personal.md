# personal (friends, family)

Light on purpose. Stays in the owner's private area; never summarized into another project or the brain inbox.

- **Header**: who, date.
- **Promises**: who promised what, to whom, date only if spoken.
- **Ideas**: things mentioned worth trying (places, books, gifts, plans), one line each.
- **Contacts**: names, numbers, links shared, flagged if heard once.
- **Dates**: birthdays, trips, events mentioned.

No gist, no analysis, no quotes beyond what a promise needs.
