# Sources

Ideas this skill borrows, with thanks:

- Granola, templates and notes by meeting type: https://docs.granola.ai/help-center/taking-notes/customise-notes-with-templates and https://www.granola.ai/blog/meeting-note-templates-by-type (a template is a list of sections with one-line prompts; the owner's own jottings steer what gets expanded).
- vstlmkh/summarizing-meetings (github.com/vstlmkh/summarizing-meetings): summarizing meetings from transcripts with a fixed structure.
- hsyeo4568/meeting-minutes-skill (github.com/hsyeo4568/meeting-minutes-skill): a minutes skill with decisions and action items as first-class sections.
- s1vanov/follow-up (github.com/s1vanov/follow-up): follow-up message drafting after a meeting.
